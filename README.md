Repositório de estudos e práticas de **visualização de dados em Python**, com foco no uso das bibliotecas **Matplotlib** e **NumPy**.

Este repositório reúne diferentes exercícios e exemplos de gráficos desenvolvidos durante meu processo de aprendizagem, incluindo gráficos de barras, linhas, funções trigonométricas e outras formas de visualização.

Os códigos são baseados e inspirados em exemplos encontrados no **GeeksforGeeks**, com modificações e adaptações realizadas durante os estudos.

# Sobre o Repositório

**Visualizações de Dados com Python** é um projeto pessoal de estudos criado para praticar conceitos de visualização de dados utilizando Python.

O principal objetivo é desenvolver familiaridade com a biblioteca Matplotlib, compreender a estrutura e os principais parâmetros utilizados na criação de gráficos e praticar a manipulação de dados com NumPy.

Os exemplos são utilizados como exercícios práticos e podem ser modificados ou adaptados conforme o avanço dos estudos.

O repositório será atualizado conforme novos exercícios forem desenvolvidos.

# Tópicos Praticados

Os exercícios deste repositório abordam diferentes tipos de visualização e conceitos relacionados ao Matplotlib e NumPy:

- Gráficos de barras
- Barras horizontais
- Barras múltiplas
- Barras sobrepostas
- Gráficos de linhas
- Linhas múltiplas
- Marcadores
- Rótulos e anotações
- Preenchimento de áreas entre linhas
- Funções trigonométricas
- Personalização de gráficos
- Títulos e legendas
- Eixos e rótulos
- Escalas e intervalos
- Barras de erro
- Manipulação de posições com NumPy
